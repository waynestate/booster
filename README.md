# BOOSTER

BOOSTER is the upgrade tool: Rector recipes and checks that move an app from one PHP or Laravel version to the next in one command. It is part of WELD, the Wayne State application stack, beside WayneUI, CREED, PROCTOR, PREFLIGHT, SESAME, HELMET, Pinstripe and Sourdough.

> A booster shot keeps your immunity current. This one keeps your PHP current, and it stings less.

Status: scaffolding. The 0.1 build is under way.
