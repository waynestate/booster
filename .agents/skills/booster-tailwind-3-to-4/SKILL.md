# tailwind-3-to-4

Generated by `booster init`. Do not edit by hand.

Move a Tailwind CSS 3 front end to Tailwind CSS 4 with the official upgrade tool.

1. `booster run --path=<app> --dry-run` and read every diff.
2. `booster run --path=<app>` applies the plan and stops at the first failing gate.
3. If a hop is capped, split the work with `--skip`; do not raise `--max-changes` blindly.

What Rector cannot do (check these by hand):

- Booster runs npx @tailwindcss/upgrade, then pins tailwindcss to ^4.1, adds the matching Vite or PostCSS plugin, and removes autoprefixer and postcss-import, which Tailwind 4 folds in.
- MANUAL: plugins listed in tailwind.config.js are not migrated by the tool; move their logic into CSS @plugin or @utility rules by hand.
- MANUAL: @apply inside Vue SFC <style> blocks needs @reference "tailwindcss" at the top of the block, or the classes do not resolve.
- Tailwind 4 raises the browser floor: Safari 16.4+, Chrome 111+, Firefox 128+. Check the app's supported browsers before you ship.

Official notes:

- https://tailwindcss.com/docs/upgrade-guide
