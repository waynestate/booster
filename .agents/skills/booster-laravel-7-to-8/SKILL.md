# laravel-7-to-8

Generated by `booster init`. Do not edit by hand.

Move a Laravel 7 app to Laravel 8.

1. `booster run --path=<app> --dry-run` and read every diff.
2. `booster run --path=<app>` applies the plan and stops at the first failing gate.
3. If a hop is over the review threshold (200 files), read its per-rule summary, then apply it with `--max-changes=N`. Use `--skip` to leave a rule out.

When a gate fails, the run stops and leaves this hop's changes in place:

1. Read the report for this hop: the phase that failed and the last lines of output. Work from that exact output, the files it names, their tests and the notes below, not from a summary of them.
2. Fix one cause: code the hop could not change, a package that blocks the hop (`booster plan` names it), or a test that depends on old behavior.
3. Commit the fix on its own, then run `booster run --path=<app>` again. Booster plans from the versions the app is on now, so finished hops are not repeated.
4. Stop after 3 tries at the same failure, or sooner when a try changes nothing. Show the person the last output and what you tried.

Never delete, skip or loosen a test to turn a gate green, and never add `--skip-gate`, `--allow-failing-baseline` or `--skip` unless the person asks for it.

Only if the app has Laravel Boost (`booster detect` says so):

- Use `search-docs` for the Laravel 8 upgrade guide and list every breaking change that touches this app's `list-routes` and `get-config` output.
- Use `database-schema` to look at the tables, and check the database server's version against the minimum Laravel 8 needs, before you apply the hop.
- Use `list-artisan-commands` and `list-routes` before the hop, then compare the output after it.
- Run `last-error` and `read-log-entries` after the tests.

Boost is read-only help. Booster's gate stays the authority: never skip a gate because Boost says so.

What Rector cannot do (check these by hand):

- If your database server is old, check its version against the minimum MySQL (or other database) version Laravel 8 needs before you apply this hop.
- Update first-party packages (Sanctum, Livewire, Inertia) and your own forks by hand; Rector does not touch them.
- Inertia: Booster pins no inertia-laravel or @inertiajs/vue3 constraint for Laravel 8; check the Inertia docs for the versions that support it.
