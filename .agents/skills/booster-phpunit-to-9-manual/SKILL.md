# phpunit-to-9-manual

Generated by `booster init`. Do not edit by hand.

Move PHPUnit to ^9 by hand: PHPUnit below 9 does not run on PHP 8, so later gates cannot run until it moves.

Booster has no automatic change for this hop. Follow the official guide below, then run the tests.

Only if the app has Laravel Boost (`booster detect` says so):

- Use `search-docs` for the PHPUnit 9 migration notes and list the changes that touch this app's tests.
- Use `get-config` to read the app's test-related config before you change phpunit.xml.
- Run `last-error` and `read-log-entries` after the tests.

Boost is read-only help. Booster's gate stays the authority: never skip a gate because Boost says so.

What Rector cannot do (check these by hand):

- Raise phpunit/phpunit to ^9.5 in require-dev.
- Replace setUp() and tearDown() without : void.
- Replace assertInternalType and @expectedException.
- Run the tests.

Official notes:

- https://phpunit.de/articles/migrating-to-phpunit-9.html
