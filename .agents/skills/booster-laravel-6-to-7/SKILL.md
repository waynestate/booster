# laravel-6-to-7

Generated by `booster init`. Do not edit by hand.

Move a Laravel 6 app to Laravel 7.

1. `booster run --path=<app> --dry-run` and read every diff.
2. `booster run --path=<app>` applies the plan and stops at the first failing gate.
3. If a hop is capped, split the work with `--skip`; do not raise `--max-changes` blindly.

What Rector cannot do (check these by hand):

- Check the shared database server against the Laravel 7 database floor before you apply this hop.
- Update first-party packages (Sanctum, Livewire, Inertia) and your own forks by hand; Rector does not touch them.

Official notes:

- https://laravel.com/docs/7.x/upgrade
