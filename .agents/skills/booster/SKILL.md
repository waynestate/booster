# BOOSTER

Generated by `booster init`. Do not edit by hand; run `booster init` again.

1. Run `booster detect --path=<app>` and read the app type and versions.
2. Run `booster plan --path=<app>` (or `--goal=php-74-to-84`) and show the plan to the person.
3. For each step, follow the matching playbook below. Never skip a gate.
4. Stop when the plan is done. A person reviews the diff and merges. Never push.

Playbooks:

- `booster-php-56-to-70`: Move PHP 5.6 code to PHP 7.0.
- `booster-php-70-to-71`: Move PHP 7.0 code to PHP 7.1.
- `booster-php-71-to-72`: Move PHP 7.1 code to PHP 7.2.
- `booster-php-72-to-73`: Move PHP 7.2 code to PHP 7.3.
- `booster-php-73-to-74`: Move PHP 7.3 code to PHP 7.4.
- `booster-php-74-to-80`: Move PHP 7.4 code to PHP 8.0.
- `booster-php-80-to-81`: Move PHP 8.0 code to PHP 8.1.
- `booster-php-81-to-82`: Move PHP 8.1 code to PHP 8.2.
- `booster-php-82-to-83`: Move PHP 8.2 code to PHP 8.3.
- `booster-php-83-to-84`: Move PHP 8.3 code to PHP 8.4.
- `booster-php-84-to-85`: Move PHP 8.4 code to PHP 8.5.
- `booster-laravel-8-to-9`: Move a Laravel 8 app to Laravel 9.
- `booster-laravel-9-to-10`: Move a Laravel 9 app to Laravel 10.
- `booster-laravel-10-to-11`: Move a Laravel 10 app to Laravel 11.
- `booster-laravel-11-to-12`: Move a Laravel 11 app to Laravel 12.
- `booster-laravel-12-to-13`: Move a Laravel 12 app to Laravel 13.
- `booster-phpunit-9-to-10`: Move PHPUnit 9 tests to PHPUnit 10.
- `booster-phpunit-10-to-11`: Move PHPUnit 10 tests to PHPUnit 11.
- `booster-phpunit-11-to-12`: Move PHPUnit 11 tests to PHPUnit 12.
- `booster-phpunit-12-to-13`: Move PHPUnit 12 tests to PHPUnit 13.
- `booster-cas-to-sesame`: Swap the wayne-cas package for SESAME using its compatibility classes (stub recipe).
- `booster-node-pin-24`: Pin the app to Node 24: set engines.node in package.json and write .nvmrc.
- `booster-mix-to-vite`: Move a simple Laravel Mix front end to Vite (simple webpack.mix.js files only).
- `booster-vue-2-to-3`: Move a Vue 2 front end to Vue 3 (playbook only; Rector does not read Vue).
